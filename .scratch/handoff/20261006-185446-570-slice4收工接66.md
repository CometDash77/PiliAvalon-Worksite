## 环境事实(接手必读,全为本机实测)

- flutter/dart 均不在 PATH:`D:\flutter-sdk\flutter\bin\flutter.bat`(Flutter 3.47.2)、`D:\flutter-sdk\flutter\bin\dart.bat`。
- **本机性能跑不动 flutter test**(YG 明确指示),测试一律走 GitHub Actions:codex 分支 push 不触发 ci.yml(push 仅 main/production),要手动 `gh workflow run ci.yml --ref <branch>`,再用 `gh run watch <runId> --exit-status` 盯(后台 job)。gate = 全量 flutter test + flutter analyze,约 12-15 分钟。
- 本地只做单文件 analyze:`dart.bat analyze <file>`(注意 `dart analyze` **没有** `--no-pub`,那是 flutter analyze 的参数)。tool/probe/ 的 11 个 info 被 `.git/info/exclude` 排除,CI 看不到,别被本地噪音骗。
- pwsh 工具结果的 exitCode 可能被 stderr 的 NativeCommandError 折叠污染,**真实退出码看 $LASTEXITCODE**。
- 大日志落盘(如 `gh run view --log > 文件`)后 read 工具可能判 binary 拒读;用 grep 工具(支持 UTF-8 emoji)或 pwsh `Select-String` 提取。失败测试行前缀是 ❌/##[group],✅ 行是过测;"Startup failed" 类 stderr 噪音可能是 ✅ 测试的预期输出。
- `gh api .../jobs/<id>/logs` 重定向产物是 zip 而非文本,别踩;完整日志用 `gh run view <id> --log`。
