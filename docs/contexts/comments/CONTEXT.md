# 评论过滤

评论可见性决定评论是否进入主评论、楼中楼、对话和首页评论门控的可见结果。

## Language

**评论语义标准**：（已退役，issue #122）旧「评论过滤标准」配置模型，已并入 typed 评论规则。存量标准文本由 JevCommentCriteriaMigration 幂等迁移为一条评论目标 noul 规则（阈值 0.95）后删除原键。

**评论规则**：用户在「判断规则」中为评论目标编写的 typed 规则（多条自然语言条件，逐条启停、逐条阈值），是评论语义过滤的唯一配置源。它判断评论正文，不从推荐视频的负面主题推导评论偏好。

**可见评论**：通过现有评论规则后仍保留的评论；语义不确定或服务失败时保留。

**首页评论门控**：用户开启后，检查推荐视频是否存在可见评论的步骤。当前抽样页未耗尽、未取得评论或判断失败时保留视频。
